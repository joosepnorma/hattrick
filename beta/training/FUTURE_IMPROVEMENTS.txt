Performance Optimizations (No Loss of Specificity):
===================================================
Ordered by estimated impact (highest first).

1. Pre-compute Sim Teams Once [ALREADY IMPLEMENTED]
   - meta_simulator.js line 114 calls precomputeRatings() once per team.
   - Precomputed simTeam (with cubic powers) is reused for all matches.
   - Impact: Already achieved ~30-40% speedup.

2. Cache Team Generation by Profile Hash [IMPLEMENTED]
   - teamCache Map with hashProfile() in meta_simulator.js.
   - Neutral overhead for unique profiles, ~20%+ savings for duplicates.

3. Typed Arrays for Stamina Tables [IMPLEMENTED]
   - STAMINA_FLAT_NORMAL and STAMINA_FLAT_PRESSING Float32Arrays.
   - getStaminaMultiplier() uses indexed lookup, no parseFloat().
   - Impact: ~10-15% speedup in stamina calculations.

4. Pre-compute Object.keys() in Hot Paths [IMPLEMENTED]
   - _lineup_keys and _lineup_sums cached in precomputeRatings().
   - _countPlayers() uses cached values with fallback.
   - Impact: ~5-10% speedup in SE calculation.

5. Batch Random Number Generation [NOT RECOMMENDED]
   - Modern V8/SpiderMonkey have highly optimized Math.random().
   - Array overhead often makes this slower, not faster.
   - Remove from consideration.

6. Inline Simple Math Functions [IMPLEMENTED]
   - Inlined applySectorPhysics and roundHattrick in rating functions.
   - Removes function call overhead in lineup_engine.js.
   - Impact: ~2-5% speedup in rating calculations.

7. Web Workers for Parallel Simulation
   - Move match simulation to background thread.
   - Prevents UI freezing, enables multi-core utilization.
   - Impact: UI responsiveness + potential parallelism.
